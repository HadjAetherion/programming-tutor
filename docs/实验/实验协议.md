# 实验协议（准实验设计）

**题目**：面向在线编程学习的多智能体协同诊断与自适应辅导系统设计与实现
**实验日期**：2026 年 11 月
**对象**：程序设计入门课程学生（本科一年级）

---

## 1. 研究假设

| 编号 | 假设 | 对应创新点 |
|---|---|---|
| H1 | 使用"大小模型协同"系统的学生，**学习效果**（后测-前测增益）优于"全云端"对照组 | 创新点① |
| H2 | 协同组**认知负荷**（NASA-TLX 加权分）不高于对照组 | — |
| H3 | 协同组**推理成本**与**响应延迟**显著低于对照组 | 创新点②③ |
| H4 | 协同组教学反馈质量（人工评分）与对照组无显著差异 | 创新点③（成本-质量联合） |

H1 与 H4 共同构成**成本-质量联合评估**（创新点③）：若质量不降而成本/延迟显著下降，即证明路由策略有效。

---

## 2. 实验设计

- **类型**：非随机对照准实验（两班/两批次自然分组）
- **自变量**：辅导系统架构
  - **实验组**：轻量路由决策器开启（`ROUTER_FORCE_TIER` 留空）→ 按任务异质性在端侧小模型（Ollama qwen2.5:7b）与云端大模型（智谱 glm-4.7-flash）间动态选择
  - **对照组**：强制全云端（`ROUTER_FORCE_TIER=cloud`）→ 等价于"统一大模型"基线
- **因变量**：学习效果、认知负荷、推理成本、响应延迟
- **控制变量**：同一批题目、同一份前后测卷、同一时长（90 分钟）、同一教学环境

---

## 3. 实验流程（单场次约 90 分钟）

| 环节 | 时长 | 内容 |
|---|---|---|
| 1. 说明与知情同意 | 10 min | 介绍系统与任务，签署知情同意 |
| 2. **前测**（pre-test） | 15 min | 独立完成笔试卷，不借助系统与 AI |
| 3. 系统练习 | 45 min | 在题库中作答（从 26 题中指定 6 题）；提交未通过自动触发多智能体诊断与辅导。允许反复提交 |
| 4. **后测**（post-test） | 15 min | 独立完成同难度后测卷 |
| 5. NASA-TLX 问卷 | 5 min | 填写认知负荷量表 |

> 前测卷与后测卷**题型、题量、难度一致**（可互换的平行卷），避免练习效应。

---

## 4. 分组与操作步骤

1. 实验组学生注册使用系统正常流程。
2. 对照组由实验组织者在**启动前**设置环境变量：

```env
# start.bat 所在目录的 .env
ROUTER_FORCE_TIER=cloud
```

3. 启动前清空或保留同一套数据。对照组与实验组使用**不同的用户群体**，无需清库。
4. 参与者分配分组记录：

```sql
INSERT INTO experiment_groups (user_id, group_name)
SELECT id, 'experimental' FROM users WHERE email IN ('a@x.com', 'b@x.com');
```

---

## 5. 指标测量

| 指标 | 测量方式 |
|---|---|
| **学习效果** | 后测分 - 前测分（gain score），写入 `assessment_scores` |
| **认知负荷** | NASA-TLX 六个维度 0-100，加权总分写入 `nasa_tlx` |
| **推理成本** | `llm_call_log.cost_yuan` 按组汇总；端侧模型成本为 0 |
| **响应延迟** | `llm_call_log.latency_ms` 按模型层分组统计；另有全流程墙钟时间 `submission_diagnosis.latency_ms` |
| **系统可用性** | 提交次数、ACCEPTED 率、诊断触发次数 |

数据导出与统计：运行 `scripts/analysis.py`（见第 7 节）。

---

## 6. 伦理与数据处理

- 参与者签署知情同意，可随时退出
- 只采集学习行为数据（提交记录、诊断结果、问卷），不采集身份敏感信息
- 论文中所有数据**匿名化**呈现（用 ID 代替姓名）
- 遵守学校研究伦理规范

---

## 7. 分析脚本

```bash
# 依赖仅 asyncpg（agent-service 的 venv 已包含）
cd agent-service
.venv/Scripts/python.exe ../scripts/analysis.py --out ../docs/实验/analysis_report.md
```

脚本输出：
- 各组人数、前测/后测均值与增益
- 推理成本/平均延迟按组与模型层对比（**创新点③核心表**）
- Mann-Whitney U 检验与效应量（小样本可用）
- NASA-TLX 各维度均值对比
