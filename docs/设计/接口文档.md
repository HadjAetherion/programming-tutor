# 接口文档

**项目**：面向在线编程学习的多智能体协同诊断与自适应辅导系统
**版本**：v1.0
**基础地址**：Go 后端 `http://localhost:8080/api/v1`；Agent 服务 `http://localhost:8000/api/v1`

---

## 0. 通用约定

- **认证**：除注册/登录外，均需请求头 `Authorization: Bearer <JWT>`
- **编码**：`Content-Type: application/json`，UTF-8
- **错误响应**：

```json
{ "error": "错误简述", "detail": "可选详情" }
```

| 状态码 | 含义 |
|---|---|
| 400 | 参数错误 |
| 401 | 未认证或令牌失效 |
| 404 | 资源不存在或无权限 |
| 409 | 资源冲突（如邮箱已注册） |
| 500 | 服务端错误 |
| 502 | 下游 Agent 服务调用失败 |

## 1. 认证

### 1.1 注册

`POST /auth/register`

**请求**

```json
{
  "username": "student01",
  "email": "student01@example.com",
  "password": "secret123"
}
```

**约束**：username 3-50 字符；password ≥ 6 位；email 唯一。

**响应 201**

```json
{
  "user": {
    "id": 5,
    "username": "student01",
    "email": "student01@example.com",
    "created_at": "2026-11-10T10:00:00+08:00",
    "updated_at": "2026-11-10T10:00:00+08:00"
  }
}
```

**错误**：409 `email already exists`

### 1.2 登录

`POST /auth/login`

**请求**

```json
{ "email": "student01@example.com", "password": "secret123" }
```

**响应 200**

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": { "id": 5, "username": "student01", "email": "student01@example.com", "...": "" }
}
```

**错误**：401 `invalid email or password`

### 1.3 当前用户

`GET /me`

**响应 200**

```json
{ "user": { "id": 5, "username": "student01", "email": "student01@example.com" } }
```

## 3. 运行与提交

### 3.1 运行代码（自定义输入）

`POST /submissions/run`

**请求**

```json
{
  "code": "print(1 + 2)",
  "language": "python",
  "input": ""
}
```

`language` 取值：`go` / `python` / `java` / `cpp`（亦接受 `c++`、`py`、`golang` 等别名，服务端归一）。

**响应 200**

```json
{
  "status": "FINISHED",
  "stdout": "3\n",
  "stderr": "",
  "exit_code": 0,
  "execution_time_ms": 836
}
```

**状态取值**：`FINISHED` / `COMPILE_ERROR` / `RUNTIME_ERROR` / `TIME_LIMIT`

**错误**：400 `unsupported language`（附 `supported_languages`）

### 3.2 提交判题

`POST /submissions/submit`

**请求**

```json
{
  "problem_id": 101,
  "code": "import math\nr=float(input())\nprint(f'{3.14159265*r*r:.2f}')",
  "language": "python"
}
```

**响应 200**

```json
{
  "id": 36,
  "status": "ACCEPTED",
  "passed_tests": 4,
  "total_tests": 4,
  "stdout": "3.14\n",
  "stderr": "",
  "exit_code": 0,
  "execution_time_ms": 3051
}
```

**说明**：状态为 `ACCEPTED` 时，后端会异步上报学情（不阻塞本响应）。

### 3.3 我的提交列表

`GET /submissions`

**响应 200**

```json
{
  "submissions": [
    {
      "id": 36,
      "problem_id": 101,
      "language": "python",
      "status": "ACCEPTED",
      "exit_code": 0,
      "execution_time_ms": 3051,
      "has_diagnosis": false,
      "created_at": "2026-11-10T10:05:00+08:00"
    }
  ]
}
```

`has_diagnosis` 由 `LEFT JOIN submission_diagnosis` 得出，供前端显示"已诊断"标记。

### 3.4 提交详情

`GET /submissions/:id`

**响应 200**：完整 Submission（含 `code`、`stdout`、`stderr`、`passed_tests`、`total_tests`）

## 4. 诊断辅导

### 4.1 触发诊断（长耗时）

`POST /submissions/:id/diagnose`

**说明**：同步执行四 Agent 流程。云端限流下耗时可达 2-4 分钟，**前端超时需 ≥ 300s**。

**响应 200**

```json
{
  "diagnosis": {
    "id": 20,
    "submission_id": 39,
    "user_id": 1,
    "error_type": "逻辑错误",
    "root_cause": "代码将输入的字符串直接相加，没有进行类型转换",
    "concepts": ["输入输出", "数据类型", "运算符"],
    "explanation": "...",
    "hint": "...",
    "feedback": {
      "tutoring_style": "scaffold",
      "content": "你好！这道题的关键在于处理输入的数据类型...",
      "guiding_questions": ["input() 返回的是什么类型？", "..."],
      "code_example": ""
    },
    "review": {
      "overall_score": 60,
      "strengths": ["结构清晰"],
      "issues": [
        {
          "severity": "high",
          "category": "边界",
          "message": "未处理非法输入",
          "suggestion": "增加类型判断"
        }
      ],
      "summary": "..."
    },
    "planning": {
      "summary": "你在\"两数之和\"这道题上遇到了挑战...这正好对应了你学情中薄弱的\"输入输出\"和\"数据类型\"模块。",
      "steps": [
        { "action": "修改代码", "detail": "将输入的字符串转换为整数类型" },
        { "action": "巩固练习", "detail": "复习 int() 的使用" }
      ],
      "next_problem_hint": "建议练习一道涉及用户输入处理和类型转换的题目"
    },
    "model_name": "qwen2.5:7b,glm-4.7-flash",
    "model_tier": "mixed",
    "latency_ms": 246593,
    "prompt_tokens": 1696,
    "completion_tokens": 2373,
    "cost_yuan": 0,
    "created_at": "..."
  }
}
```

**字段说明**

| 字段 | 说明 |
|---|---|
| `model_tier` | `edge` / `cloud` / `mixed`（混合） |
| `feedback.tutoring_style` | `direct_hint` / `socratic` / `scaffold` |
| `review.issues[].severity` | `high` / `medium` / `low` |

**错误**：404（提交不存在或非本人）、502（Agent 服务失败，含 `detail`）

### 4.2 读取已存诊断

`GET /submissions/:id/diagnosis`

**响应 200**：同上 `diagnosis` 对象；无记录时返回 `{"diagnosis": null}`。

**说明**：只读接口，不触发任何模型调用。

## 5. 学情与统计

### 5.1 我的掌握度

`GET /me/mastery?language=go`

`language` 可选；省略返回全部语言。

**响应 200**

```json
{
  "mastery": [
    {
      "language": "python",
      "concept_name": "输入输出",
      "mastery": 0.35,
      "attempts": 1,
      "weakness_count": 1,
      "updated_at": "2026-11-10T10:06:00+08:00"
    }
  ]
}
```

**排序**：`language ASC, mastery ASC`（最薄弱在前，前端直接按序渲染）

### 5.2 我的调用统计

`GET /me/llm-stats`

**响应 200**

```json
{
  "stats": [
    {
      "agent_role": "diagnosis",
      "model_tier": "edge",
      "calls": 3,
      "avg_latency_ms": 5621.33,
      "avg_prompt_tokens": 465.0,
      "avg_completion_tokens": 113.0,
      "total_cost_yuan": 0
    }
  ]
}
```

**用途**：仪表盘 KPI 与延迟对比图、明细表的数据源。

## 7. 调用示例（curl）

```bash
# 登录
TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"student01@example.com","password":"secret123"}' \
  | python -c "import sys,json;print(json.load(sys.stdin)['token'])")

# 提交 Python 代码
curl -s -X POST http://localhost:8080/api/v1/submissions/submit \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"problem_id":101,"code":"import math\nprint(1)","language":"python"}'

# 触发诊断（长耗时，需设置 -m 400）
curl -s -m 400 -X POST http://localhost:8080/api/v1/submissions/36/diagnose \
  -H "Authorization: Bearer $TOKEN"

# 查看掌握度
curl -s http://localhost:8080/api/v1/me/mastery -H "Authorization: Bearer $TOKEN"
```

> Windows 下用 curl 传中文需注意终端编码（GBK 会报 Invalid UTF-8），建议用 ASCII 测试数据或改用脚本提交。
