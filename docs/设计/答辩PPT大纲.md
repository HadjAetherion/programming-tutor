## 可能被问到的问题与准备

1. **为什么用规则路由而不是学习型路由？**
   → 可解释、可复现、无需训练数据；小样本实验下规则更可信。可作为展望。

2. **端侧模型质量够吗？**
   → 路由只把"低阶任务"交给端侧（编译错误定位、短代码审查）；复杂逻辑仍走云端；H4 用人工评分验证质量不降。

3. **掌握度模型为什么不用 BKT/DKT？**
   → 参数少、可解释、可在 SQL 层实现；BKT 需估计 guess/slip，小样本不可靠。

4. **四个 Agent 会不会重复劳动？**
   → 职责边界明确：审查不判断对错、诊断不评价代码质量；提示词中显式约束。

5. **学生会不会直接抄 AI 的答案？**
   → 反馈策略禁止给出完整代码；scaffold 仅允许极小片段；这是设计约束（FR-3.8）。

6. **成本为什么是 0？**
   → 当前使用免费额度；以 Token 作为成本代理指标，并说明商用单价折算后差异同向。
